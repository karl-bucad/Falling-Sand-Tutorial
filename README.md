# Falling Sand Simulation

An interactive particle simulation built with JavaScript and HTML Canvas, based on the Falling Sand tutorial by Aidan Keighron.

## Features

* Sand and dirt fall under gravity and interact with water.
* Water flows and turns dirt into grass.
* Fire spreads to neighboring wood and converts water into steam.
* Steam rises and can condense back into water.
* Adjustable simulation speed and brush size.

## Technologies

JavaScript, HTML, CSS, HTML Canvas
